# Домашние задания по Go

Репозиторий с домашними заданиями к Go-курсу. Каждое задание — отдельная
команда в `cmd/`, общий код — в `internal/`.

## Структура

```text
.
├── cmd/
│   └── app/           # точка входа (заготовка, можно переименовать под задание)
│       └── main.go
├── internal/
│   └── app/           # логика приложения и тесты
│       ├── app.go
│       └── app_test.go
├── .gitignore
├── go.mod
└── README.md
```

## Требования

- Go 1.27+

## Команды

```bash
go run ./cmd/app      # запустить приложение
go build ./...        # собрать все пакеты
go test ./...         # запустить тесты
go test -race ./...   # тесты с детектором гонок
go vet ./...          # статический анализ
gofmt -l .            # проверить форматирование
```

## Как добавить домашнее задание

1. Создайте команду: `cmd/homework1/main.go` с `package main`.
2. Общий код вынесите в `internal/...`.
3. Запустите `go test ./...` и `gofmt -w .`.

Если репозиторий будет публиковаться, поменяйте путь модуля:

```bash
go mod edit -module github.com/<user>/homeworks
```
